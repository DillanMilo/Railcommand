# Universal Links and Android App Links

The app declares `railcommand://` callbacks plus an environment-specific verified HTTPS
host. Development and staging builds use
`mobile-staging.railcommand.io`;
production uses `railcommand.io`. Association endpoints are generated by the Next.js
app and bypass login middleware because Apple and Google fetch them without a user
session.

Association discovery is **online-only infrastructure**. It stores no project or user
data and does not change the app's offline draft/outbox guarantees.

## Apple

Staging publishes the development and staging Apple application identifiers with
`application/json` and no redirect at:

- `https://mobile-staging.railcommand.io/.well-known/apple-app-site-association`

The previous staging host was accepted by Apple's association CDN on 2026-08-25. The
replacement isolated host must be rechecked after this branch is deployed. The
production route is coded to emit only the production identifier, but it must not be
deployed to the live site until release approval. Its eventual endpoint is:

- `https://railcommand.io/.well-known/apple-app-site-association`

The current Apple Team ID is `PQAGLH9L66`. Confirm it in the signed Xcode account before
publishing. Test both a cold launch and an already-running callback.

## Android

Staging publishes only `io.railcommand.app.dev` with the exact debug certificate
fingerprint used by the verified APK at:

- `https://mobile-staging.railcommand.io/.well-known/assetlinks.json`

Google's Digital Asset Links API independently resolved the previous staging host on
2026-08-25. The replacement isolated host must be rechecked. Production intentionally
returns no Android association unless
`MOBILE_ANDROID_PRODUCTION_SHA256` contains one or more approved SHA-256 Play App
Signing certificate fingerprints. The eventual production endpoint is:

- `https://railcommand.io/.well-known/assetlinks.json`

Development/debug, Play App Signing, and upload certificates have different
fingerprints. Never publish the debug or upload fingerprint for the production package.
Verify the final installed Play build with Android App Links tooling before release.

## Accepted callback scope

The shared domain contract defaults to `railcommand.io`; a development or staging build
must explicitly inject its guarded staging hostname. Auth callbacks must contain a
valid PKCE `code`, a token-hash/type pair, or a complete access/refresh token pair.
Incomplete and foreign callbacks are rejected.
